# PR Checklist

## Scope
- [ ] Module clearly identified
- [ ] No unnecessary service touched
- [ ] Frontend touched only if contract required

## Design
- [ ] Canonical flow preserved
- [ ] Status and decision semantics respected
- [ ] No silent API contract break

## Quality
- [ ] Build passes
- [ ] Lint passes
- [ ] Relevant tests added or updated
- [ ] Regression risk reviewed

## Documentation
- [ ] Relevant docs updated
- [ ] Any new rules captured in docs
