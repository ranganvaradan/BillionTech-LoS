## Explicit note: PERFIOS

**PERFIOS** is listed as the **primary** route for several steps in `aggregator_routing`, but the Spring bean **does not call Perfios APIs today**. It **delegates to `KarzaKycProvider`**, so **routing, audit, and UI** can show `PERFIOS` while behavior matches Karza. Replacing this with a **real Perfios** (or other primary) client is a **dedicated project**: contracts, UAT, error taxonomy, and possibly different payload shapes per product.
